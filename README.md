# DataCollectProjectX

The repository consists of 3 projects: sis1, sis2 and final exam.
SIS 2 is dedicated to the collection, processing and analysis of data on air quality in five cities of Kazakhstan: Almaty, Astana, Shymkent, Karaganda and Atyrau.
Receive the data through the Open-Meteo air Quality API, transmit them through Apache Kafka, verify their correctness using Pandera, clean and transform them through pandas and NumPy, and then save them to the SQLite3 database.
