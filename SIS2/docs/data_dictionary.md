# Data Dictionary

Raw records collected from the Open-Meteo Air Quality API (`data/raw_data.csv`) and consumed from Kafka (`data/consumed_data.csv`).

| Column | Type | Kind | Description | Example |
|---|---|---|---|---|
| record_id | string | identifier | unique id: city + hour | `Almaty_2026-11-17T00:00` |
| city | string | categorical | one of: Almaty, Astana, Shymkent, Atyrau, Karaganda | `Almaty` |
| latitude | float | numerical | latitude of the API grid point | `43.199997` |
| longitude | float | numerical | longitude of the API grid point | `76.899994` |
| timestamp | string (ISO date/time) | date/time | hour of the measurement, local time (Asia/Almaty) | `2026-11-17T00:00` |
| pm2_5 | float | numerical | fine particles, diameter below 2.5 μm, μg/m³ | `24.9` |
| pm10 | float | numerical | particles, diameter below 10 μm, μg/m³ | `25.6` |
| us_aqi | integer | numerical | US Air Quality Index (0-500, higher = worse air) | `82` |
| collected_at | string (ISO date/time) | date/time | when the data was collected | `2026-11-24T16:05:24` |

## Columns added in the cleaning stage

Cleaned data (`data/cleaned_data.csv`) and the SQLite table `air_quality` (`data/output.db`) contain all columns above plus:

| Column | Type (pandas / SQLite) | Kind | Description | Example |
|---|---|---|---|---|
| date | date / TEXT | date/time | calendar day of `timestamp` | `2026-11-17` |
| hour | int / INTEGER | numerical | hour of day 0-23 (local time) | `20` |
| day_of_week | string / TEXT | categorical | weekday name | `Tuesday` |
| is_weekend | bool / INTEGER (0/1) | categorical | Saturday or Sunday | `0` |
| pm_ratio | float / REAL | numerical | pm2_5 / pm10 (share of fine particles) | `0.973` |
| log_pm2_5 | float / REAL | numerical | `log(1 + pm2_5)`, reduces skewness | `3.254` |
| pm2_5_zscore | float / REAL | numerical | (pm2_5 - city mean) / city std | `0.61` |
| above_who_pm2_5 | bool / INTEGER (0/1) | categorical | pm2_5 above WHO 24-h guideline (15 μg/m³) | `1` |
| above_who_pm10 | bool / INTEGER (0/1) | categorical | pm10 above WHO 24-h guideline (45 μg/m³) | `0` |
| aqi_category | string / TEXT | categorical | US AQI level (table below) | `Moderate` |

## SQLite schema (`data/output.db`)

- `air_quality` - one row per city and hour. `record_id` is the **PRIMARY KEY**, `(city, timestamp)` is **UNIQUE**, CHECK constraints on city, hour, pm2_5, pm10 >= pm2_5 and us_aqi. Rows are inserted with `INSERT ... ON CONFLICT DO NOTHING`, so loading the same data again adds nothing.
- `load_log` - one row per load run: time, processed, inserted, skipped, rows in table.
